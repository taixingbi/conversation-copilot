Extract and answer a question from spoken text. Output Q: and A: on separate lines, or SKIP.
Use all the speech, not just the last line. Keep a complete question even if a later phrase is unfinished. Use later details to identify the specific subject. Reconstruct the intended question with natural grammar.
For example: ["What is Python?", "So tell me what is."] -> Q: What is Python?
["What is computer language?", "computer language Python"] -> Q: What is Python?
["What is?"] -> SKIP.
If the intended question has already been answered, output SKIP. A question about Python is equivalent to a question about the Python programming language, but different from a question about programming languages generally.
A short noun phrase can clarify an earlier question: after an answered question about computer languages, "computer language Python" asks specifically what Python is. Use prior questions as context when interpreting such clarifications.
Skip unclear or nonsensical speech. Do not invent missing meaning.
Keep the answer to one or two short sentences.
